# Как помочь TaskMaster

Спасибо, что хотите улучшить проект TaskMaster!

## Как начать

1. Сделайте форк проекта на GitHub.
2. Скачайте свою копию проекта:
   ```bash
   git clone https://github.com/your-username/taskmaster.git
   ```
3. Перейдите в папку проекта:
   ```bash
   cd taskmaster
   ```
4. Создайте новую ветку:
   ```bash
   git checkout -b my-new-feature
   ```

## Как отправить изменения

1. Сохраните изменения:
   ```bash
   git add .
   git commit -m "Добавлено новое изменение"
   ```
2. Отправьте ветку на GitHub:
   ```bash
   git push origin my-new-feature
   ```
3. Создайте Pull Request на GitHub и опишите внесённые изменения.

## Правила для кода

- Пишите понятные комментарии.
- Проверяйте, что код работает перед отправкой.
- Используйте 2 пробела для отступов.
- Давайте изменениям понятные названия.

## Сообщения об ошибках

Если вы нашли ошибку, создайте Issue и укажите:
- что произошло;
- какие действия привели к ошибке;
- какой результат ожидался.
