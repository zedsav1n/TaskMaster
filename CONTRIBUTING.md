# Как помочь TaskMaster

Спасибо, что хотите улучшить наш проект!
Любая помощь полезна: исправление опечаток, новые функции, перевод или просто сообщение об ошибке.

## Как начать

1. Сделайте копию проекта (форк) на GitHub — кнопка **Fork** в правом верхнем углу.
2. Скачайте проект на свой компьютер:
   ```bash
   git clone https://github.com/taskmaster-teams/taskmaster.git
   ```
3. Перейдите в папку проекта:
   ```bash
   cd taskmaster
   ```
4. Установите зависимости:
   ```bash
   npm install
   ```
5. Создайте новую ветку для ваших изменений:
   ```bash
   git checkout -b my-new-feature
   ```

## Как отправить изменения

1. Сохраните изменения с понятным сообщением:
   ```bash
   git commit -m "Добавлена новая кнопка удаления"
   ```
2. Отправьте изменения в свой форк:
   ```bash
   git push origin my-new-feature
   ```
3. Создайте **Pull Request** на GitHub:
   - Перейдите на страницу вашего форка
   - Нажмите **Compare & pull request**
   - Опишите, что вы изменили и зачем

## Правила для кода

- **Пишите понятные комментарии** — объясняйте, что делает сложный участок.
- **Проверяйте, что код работает** — запускайте программу перед отправкой.
- **Используйте 2 пробела для отступов** — так код выглядит аккуратно.
- **Давайте веткам понятные имена** — например, `fix-login-bug` или `add-dark-mode`.
- **Один Pull Request — одна задача** — не смешивайте разные изменения.

## Сообщения об ошибках

Если нашли ошибку, но не можете её исправить:
1. Откройте новый **Issue** на GitHub.
2. Опишите, что вы делали и что произошло.
3. Приложите скриншот, если возможно.

Спасибо за ваш вклад в TaskMaster!
